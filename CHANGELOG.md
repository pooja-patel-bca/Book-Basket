# Changelog

All notable changes made to the Book Basket project are recorded in this file.

## [Version 1.0.0] - 2026-11-02

### Added

- Developed the Book Basket frontend using React.js and Vite.
- Created user registration and login functionality.
- Implemented book search and book details pages.
- Added personal library management.
- Implemented reading status management.
- Added favourite books functionality.
- Created a dashboard with reading statistics.
- Added user profile functionality.
- Integrated frontend with backend APIs.
- Connected the application to MongoDB Atlas.
- Added responsive layouts for mobile screens.
- Improved form validation and error handling.
- Updated project documentation.

### Completed

- Backend development using Node.js and Express.js.
- REST API implementation for book and library management.
- User authentication and authorization.
- MongoDB Atlas database integration.
- Frontend and backend integration.
- Book search and library operations.
- Reading status and favourite management.
- Dashboard and user interface testing.
- Initial Postman test suite: 29 out of 29 tests passed.
- Manual testing of the main application features.

## [Version 0.1.0] - 2026-10-31

### Added

- Created the initial backend project.
- Configured Node.js and Express.js.
- Connected MongoDB Atlas using Mongoose.
- Organized the backend using an MVC-style architecture.
- Created book models, controllers, routes, and middleware.
- Implemented book management APIs.
- Integrated external book search.
- Added input validation and centralized error handling.
- Configured CORS and Helmet.
- Tested backend APIs using Postman.
- Created initial project documentation.
